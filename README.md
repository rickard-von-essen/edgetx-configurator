# EdgeTX Configurator

This repository will hold the new web based Configurator for [EdgeTX](https://github.com/EdgeTX/edgetx)
to replace the [EdgeTX companion](https://github.com/EdgeTX/edgetx/tree/main/companion) and
[EdgeTX Buddy](https://github.com/EdgeTX/buddy).

It will be based on the same tech stack as the (new) [Betaflight Configurator](https://github.com/betaflight/betaflight-configurator).

## Initial setup

See the [basic application skeleton task list](SETUP_TASKS.md) for the Betaflight
tooling investigation, proposed stack, and implementation checklist. Stack and
version choices need approval before scaffolding begins.
